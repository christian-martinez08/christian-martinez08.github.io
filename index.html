1. Introducción al Encapsulamiento

El encapsulamiento es uno de los cuatro pilares fundamentales de la Programación Orientada a Objetos (POO). Consiste en ocultar los detalles internos de implementación de un objeto y proteger su estado directo frente a accesos o modificaciones no autorizadas desde el exterior.

En C#, el encapsulamiento se logra mediante el uso de modificadores de acceso y la implementación de propiedades para controlar cómo se leen y escriben las variables privadas de una clase.

2. Modificadores de Acceso en C# v5

Los modificadores de acceso definen el alcance y la visibilidad de las clases, métodos y atributos dentro del programa. A continuación se explican los principales:

a) public

El acceso no está restringido. Los miembros declarados como públicos pueden ser leídos y modificados desde cualquier parte de la aplicación o proyecto.

b) private

El acceso está limitado estrictamente al interior de la clase donde fue declarado. Ninguna otra clase o miembro externo puede acceder a él directamente.

c) protected

El acceso está restringido a la clase contenedora o a los tipos derivados (clases hijas que hereden de la clase principal).

d) internal

El acceso está limitado únicamente a los archivos que formen parte del mismo ensamblado (proyecto compilado).

3. Ejemplo Práctico en C#

A continuación se presenta un código de demostración que ilustra la implementación correcta de encapsulamiento y modificadores de acceso en una clase de C#:

using System;

namespace ManualPOO
{
    // Clase principal
    public class CuentaBancaria
    {
        // Atributo privado: Encapsulado (no accesible desde fuera directamente)
        private double saldo;

        // Atributo protegido: Accesible por clases derivadas
        protected string tipoCuenta;

        // Atributo público: Accesible desde cualquier lugar
        public string Titular;

        // Constructor
        public CuentaBancaria(string titular, double saldoInicial)
        {
            this.Titular = titular;
            this.saldo = saldoInicial;
            this.tipoCuenta = "Ahorros";
        }

        // Propiedad pública para lectura/escritura controlada del saldo
        public double Saldo
        {
            get { return saldo; }
        }

        // Método público para depositar fondos de forma segura
        public void Depositar(double monto)
        {
            if (monto > 0)
            {
                saldo += monto;
                Console.WriteLine("Depósito exitoso. Nuevo saldo: " + saldo);
            }
        }
    }
}

4. Conclusión

El uso adecuado de los modificadores de acceso permite construir sistemas software robustos, mantenibles y seguros, impidiendo la manipulación inadecuada de los datos y garantizando la integridad de las clases.
