CONTENIDO 1: ¿Cómo crear un sitio web en GitHub Pages?

El presente manual describe los pasos metodológicos necesarios para desplegar un sitio web estático utilizando la plataforma de alojamiento GitHub Pages de forma segura y directa mediante URL:

Paso 1: Creación del Repositorio

Se debe iniciar sesión en GitHub,una vez iniciado la sesión en GitHub se debe crear un nuevo repertorio.Abajo de este paso se le dejara un link directo a GitHub para que comienze a desarrolar su sitio web con los pasos dados que se le mostrara en este Manual.

Plataforma oficial de GitHub

Paso 2: Rellenar el formulario del Repositorio

Una vez completado el paso anterior, se visualizará el formulario de creación de un nuevo repositorio, tal como se observa en la siguiente imagen:

En este apartado se deben configurar los siguientes elementos clave:

  • 1. Nombre del repositorio: Se asigna el identificador del proyecto. Es importante considerar la estructura de la URL para asegurar un acceso correcto en las etapas posteriores.
  • 2. Descripción: Campo opcional que permite añadir una breve reseña sobre el propósito o contenido del sitio web.
  • 3. Visibilidad: Se selecciona el acceso público o privado de acuerdo con las necesidades de la práctica.

Paso 3: Creación y subida del archivo principal (index.html)

Una vez creado el repositorio, le daremos a creating new file. Es necesario incorporar el código fuente que estructurará la página web. Para ello, se debe crear un archivo llamado estrictamente index.html en la raíz del repositorio.

Este archivo contendrá las etiquetHTML necesarias y la información del manual, asegurando que el servidor lo reconozca automáticamente como la página de bienvenida principal al cargar la URL.

Paso 4: Activación de GitHub Pages y obtención de la URL segura

Para publicar el sitio en la web de forma accesible:

  • 1. Configuración: Diríjase a la pestaña de Settings (Configuración) en la parte superior derecha de su repositorio.
  • 2. Sección Pages: En el menú lateral izquierdo, busque y seleccione la opción Pages.
  • 3. Despliegue (Build and deployment): En el apartado de fuentes (Source), seleccione la rama principal (generalmente llamada main) y asegúrese de que esté configurada en la ruta raíz (/root), luego haga clic en guardar.
  • 4. URL final: Tras unos minutos, la plataforma generará la URL segura definitiva (por ejemplo, https://adara1234.github.io/), la cual podrá compartir para visualizar el sitio web completo.

2. Contenido Técnico: Modificadores de Acceso y Encapsulamiento en C# v5

Como parte de los requerimientos académicos, este sitio web integra la explicación y ejemplos sobre las clases en C# versión 5, centrándose en el control de acceso y el encapsulamiento.

Modificadores de Acceso

  • Public: Permite el acceso sin restricciones desde cualquier otra clase o ensamblado.
  • Private: Restringe el acceso de manera exclusiva al interior de la clase donde se declara.
  • Protected: Otorga visibilidad a la clase contenedora y a sus clases derivadas (herencia).

Ejemplo Práctico en C#

using System;

namespace ManualGitHubCSharp
{
    public class Persona
    {
        // Atributo privado (Encapsulado)
        private string cedula;

        // Atributo público
        public string Nombre;

        // Constructor
        public Persona(string nombre, string cedula)
        {
            this.Nombre = nombre;
            this.cedula = cedula;
        }

        // Método público para consultar el dato privado de forma segura
        public string ObtenerCedula()
        {
            return cedula;
        }
    }
}
