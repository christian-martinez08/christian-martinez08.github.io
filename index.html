CONTENIDO 19: ¿Cómo crear un sitio web en GitHub Pages?

El presente manual describe los pasos metodológicos necesarios para desplegar un sitio web estático utilizando la plataforma de alojamiento GitHub Pages de forma segura y directa mediante URL:

Paso 1: Creación del Repositorio

Se debe iniciar sesión en GitHub y crear un nuevo repositorio público. Es fundamental configurar el nombre del repositorio para establecer el directorio raíz del sitio.

Ir a mi perfil de GitHub 6

Paso 2: Subida del Archivo Principal

Para que el servidor reconozca la página web de manera automática, se debe agregar un archivo llamado estrictamente index.html que contenga la estructura del sitio.

Paso 3: Activación de GitHub Pages

En las opciones del repositorio, dentro de la pestaña Settings y la sección Pages, se configura la rama de despliegue (Branch) seleccionando la rama principal (por ejemplo, main) en la ruta raíz (/root). Tras unos minutos, el sistema genera la URL segura definitiva.

2. Contenido Técnico: Modificadores de Acceso y Encapsulamiento en C# v5

Como parte de los requerimientos académicos, este sitio web integra la explicación y ejemplos sobre las clases en C# versión 5, centrándose en el control de acceso y el encapsulamiento.

Modificadores de Acceso

  • Public: Permite el acceso sin restricciones desde cualquier otra clase o ensamblado.
  • Private: Restringe el acceso de manera exclusiva al interior de la clase donde se declara.
  • Protected: Otorga visibilidad a la clase contenedora y a sus clases derivadas (herencia).

Ejemplo Práctico en C#

using System;

namespace ManualGitHubCSharp
{
    public class Persona
    {
        // Atributo privado (Encapsulado)
        private string cedula;

        // Atributo público
        public string Nombre;

        // Constructor
        public Persona(string nombre, string cedula)
        {
            this.Nombre = nombre;
            this.cedula = cedula;
        }

        // Método público para consultar el dato privado de forma segura
        public string ObtenerCedula()
        {
            return cedula;
        }
    }
}
